# سَنَد الذكي — تطبيق محلي لتتبع رحلات المرافقة

تطبيق ويب يعمل على جوال ممثل سند **دون إنترنت** وبعد تثبيته من الرابط مرة واحدة. لا يتصل بأنظمة المستشفى ولا بأي خادم، ولا يطلب أو يحفظ اسمًا أو رقم ملف أو هوية أو تشخيصًا. كل البيانات تبقى على الجهاز.

## ماذا يفعل
- مسح رموز QR لنقاط المسار بالكاميرا (أو اختيار النقطة يدويًا).
- توثيق الرحلة كاملة: الذهاب، الانتظار، الخدمة، التنقل بين الخدمات، العودة حتى السيارة.
- حساب الأزمنة والمسافة المرجعية، وعدّ خطوات الممثل من مستشعر الحركة.
- تحليلات محلية: توقع مدة الرحلة، تنبيه التأخير، نقاط التعثر، ساعة الذروة، توقع طلب الغد.
- تصدير CSV بالأعمدة التي تقرؤها لوحة متابعة سند، ونسخة احتياطية.

## التثبيت على الجوال
- **أندرويد:** افتح رابط التطبيق في Chrome ← القائمة ⋮ ← «تثبيت التطبيق».
- **آيفون:** افتح الرابط في Safari ← زر المشاركة ← «إضافة إلى الشاشة الرئيسية».
- افتح الأيقونة مرة والإنترنت متصل، وبعدها يعمل دون اتصال.

## الملفات
- `index.html` التطبيق كاملًا (ملف واحد، يتضمن مكتبة jsQR بترخيص Apache-2.0).
- `sw.js` و`manifest.webmanifest` و`icons/` للتثبيت والعمل دون إنترنت.
- `print/SANAD_QR_Checkpoints.pdf` ملصقات رموز النقاط التسع للطباعة.
